# Відповіді на контрольні запитання

## 1. Що означає PWA та які переваги воно дає користувачу?

Progressive Web App — вебзастосунок із можливостями встановлення та інтеграції з пристроєм. Manifest описує застосунок, а service worker може кешувати ресурси для роботи без мережі після їх завантаження. Конкретні можливості залежать від браузера.

## 2. Яке призначення Vue-компонентів у багатосторінковому інтерфейсі SPA?

Компоненти об’єднують шаблон, логіку й стилі частини інтерфейсу. SPA перемикає сторінкові компоненти без повного завантаження нового HTML-документа; спільні елементи можна використовувати повторно.

## 3. Яку функцію виконують f7-app, f7-view і f7-page?

f7-app ініціалізує оболонку Framework7 і параметри застосунку. f7-view створює область із маршрутизатором та історією. f7-page представляє окрему сторінку з панелями й вмістом.

## 4. Чому необхідно викликати registerComponents(app)?

Функція реєструє компоненти Framework7 Vue у створеному Vue-застосунку. Без неї, за відсутності локальних імпортів, Vue не зможе коректно розпізнати компоненти f7-* у шаблонах.

## 5. Які завдання виконують Navbar і Toolbar?

Navbar — верхня панель із заголовком і навігаційними діями. Toolbar містить дії або посилання, часто внизу сторінки; у TaskFlow він використовується як нижня маршрутна панель.

## 6. Чим tabbar-подібна маршрутна панель відрізняється від f7-tabs?

Маршрутна панель відкриває сторінки за URL через маршрутизатор. f7-tabs перемикає вкладки в області поточного інтерфейсу; для маршрутизованих вкладок потрібна окрема конфігурація. У TaskFlow використані звичайні маршрутні посилання.

## 7. Як маршрутизатор Framework7 визначає потрібну сторінку?

Він зіставляє шлях переходу з path у масиві routes та завантажує відповідний component. f7-view отримує цей масив через параметри застосунку.

## 8. Яке призначення файлу routes.js?

Він централізовано описує відповідність між шляхами та сторінковими компонентами. У проєкті це /, /tasks/, /about/ і /help/.

## 9. Чому спільний AppTabbar винесено до каталогу components?

Панель повторюється на трьох основних сторінках. Спільний компонент усуває дублювання та дозволяє змінити навігацію в одному місці.

## 10. Як за допомогою props виділити активний пункт навігації?

Сторінка передає active="home", "tasks" або "about". Компонент порівнює prop зі значенням пункту й умовно додає app-link-active та aria-current="page".

## 11. Для чого застосовується директива v-for?

Вона повторює елемент або компонент для кожного запису колекції. У TasksPage.vue створює рядки завдань із масиву tasks, а на головній — три останні записи.

## 12. Яке призначення ключа :key у списку?

Унікальний стабільний ключ допомагає Vue зберігати відповідність між даними й DOM-вузлами під час оновлення, переміщення або видалення елементів. Тут використано task.id.

## 13. Яке призначення computed у HomePage.vue?

computed описує похідні значення: кількість усіх, виконаних і невиконаних завдань та останні записи. Vue кешує результат за реактивними залежностями. Поточний масив є статичними демонстраційними даними.

## 14. Навіщо демонстраційні дані винесено в tasks.js?

Це єдине джерело даних для кількох сторінок. Можна додавати записи та змінювати статуси без дублювання масивів у компонентах.

## 15. Яким чином працює CSS Grid?

Grid ділить контейнер на рядки й колонки. У проєкті repeat(3, minmax(0, 1fr)) задає три рівні колонки; медіазапит змінює структуру статистики на вузькому екрані.

## 16. Яким чином працює Flexbox?

Flexbox розміщує дочірні елементи вздовж основної осі та вирівнює їх уздовж поперечної. У рядку завдання він розташовує іконку поруч із текстом, у посиланні панелі — іконку над підписом.

## 17. Що дозволяють робити медіазапити CSS?

Вони застосовують стилі за умовами середовища, наприклад шириною viewport. У TaskFlow при max-width: 480px змінюються сітка, відступи й радіуси карток.

## 18. Чому npm run build не гарантує відсутності помилок під час запуску?

Збірка перевіряє можливість компіляції та пакування. Вона не перевіряє кожен перехід, розташування елементів, кеш PWA, мережеві запити або дії користувача — це потрібно тестувати в браузері.

## 19. Як перевірити завантаження Framework7 Icons?

Перевірити імпорт CSS іконок у main.js, успішне завантаження файлу шрифту в Network, computed font-family і вигляд іконки. Якщо замість іконки видно її назву, перевірити шрифт і підтримку лігатур.

## 20. Які дії виконати, якщо Cloudflare показує застарілу версію?

Звірити коміт і гілку деплою, перевірити успіх build/deploy та хеші ресурсів. Відкрити сайт без старого кешу. Якщо причина в PWA, перевірити Application → Service Workers; для діагностики виконати Unregister і Clear site data, враховуючи видалення локальних даних сайту, та перезавантажити сторінку.
