# Контрольні запитання

1. **Що таке компонент Vue 3?** Незалежний блок шаблону та логіки; дає повторне використання й простіший супровід.

2. **Для чого v-for?** Для побудови списку елементів або компонентів за масивом.

3. **Навіщо :key?** Для стабільної ідентифікації елементів під час оновлення або перестановки списку; використано task.id.

4. **Що таке Props?** Вхідні дані компонента, передані батьківським компонентом.

5. **Призначення defineProps()?** Оголошує вхідні властивості та їх типи, обов’язковість і типові значення у script setup.

6. **Що таке Emits і defineEmits()?** Власні події компонента; defineEmits оголошує їх та повертає функцію emit.

7. **Чому не слід змінювати Props?** Власником стану є батьківський компонент; події роблять зміну стану явною та передбачуваною.

8. **ref() і reactive()?** ref обгортає значення з доступом через .value у JavaScript; reactive повертає реактивний proxy об’єкта.

9. **Призначення computed()?** Кешує похідне значення та перераховує його при зміні реактивних залежностей.

10. **Як синхронізовано сторінки?** Вони імпортують той самий реактивний taskState із store/tasks.js.

11. **Як змінюється статус?** TaskCard обирає наступний статус, надсилає { id, status }; батько викликає setTaskStatus.

12. **Чому індикатори окремі?** Щоб повторно використовувати єдині підписи, кольори та резервні значення.

13. **Як передати payload?** Другим аргументом: emit('status-change', { id: 1, status: 'done' }).

14. **Що після перезавантаження?** Модуль сховища створюється заново з початкових демонстраційних даних.

15. **Як повторно використати TaskCard?** Імпортувати компонент, передати :task і підключити обробники трьох подій.
