# TaskFlow

Навчальний PWA-менеджер завдань на Vue 3, Framework7 і Vite.

## Запуск

```sh
npm install
npm run dev
```

Production-збірка: `npm run build`; локальний перегляд: `npm run preview`.

## Можливості

- Головна зі статистикою (10 / 3 у роботі / 3 виконано / 4 заплановано) та прогресом 30%.
- Повторно використовувані TaskCard, StatusBadge, PriorityBadge та TaskCounter.
- Спільне реактивне сховище; зміна статусу і пріоритету через Props та Emits.
- Пошук у назві та описі, поєднані фільтри, сортування, деталі та підтверджене видалення.
- Адаптивний інтерфейс, фіксована навігація, сторінки About/Help.
- PWA manifest і service worker у production-збірці.

Завдання й проєкти зберігаються в IndexedDB цього браузера та origin. Перед закриттям дочекайтеся завершення збереження. Фільтри після reload скидаються.

## Практична робота № 5 (2-8.pdf)

- TaskListControls: керований компонент з іменованими v-model для пошуку, статусу, пріоритету, сортування та швидкого фільтра.
- Видалення після підтвердження у доступному модальному діалозі; скасування кнопкою або Escape.
- Пошук одночасно у назві й описі, усі умови поєднуються; сортування не змінює вихідний масив.
- Усі 6 додаткових завдань: тільки невиконані, порядок статусів, частка виконаних у вибірці, очищення пошуку, окремий порожній список, зворотний порядок дат.
- Дата тепер необов’язкова, опис до 500 символів. Збережено категорії, форму й попередній перегляд.

Для повторення перевірок запустіть `npm run dev`, установіть Playwright (`npm install --no-save --package-lock=false playwright`) та Google Chrome, виконайте `node scripts/verify-practice5.mjs`.

Нижче збережено опис попередніх робіт; їхні тести й звіти стосуються відповідних станів проєкту. Робота № 4 доступна в коміті `9e1fb7a`.

## Практична робота № 6 (2-9.pdf)

- Pinia підключено зі збереженням Framework7; `useTasksStore` містить завдання, фільтри, getters і CRUD-actions.
- `useProjectsStore`: три демонстраційні проєкти, створення унікальних назв 3–40 символів, `projectTitle` і реактивний `projectStats`.
- Форма й картки підтримують проєкти; фільтр проєкту поєднується з текстом, статусом, пріоритетом і швидкими умовами.
- На головній показано невиконані завдання та відсоток виконання за проєктами. Групове переведення в роботу потребує підтвердження.
- `Лише без терміну` зберігається в Pinia. Переходи між сторінками зберігають фільтри; повний reload скидає дані й проєкти.
- Виправлено передачу значення сортування з TaskListControls; перевірено всі 8 режимів без переставляння вихідного масиву.

Перевірки: `npm ci`, `npm run build`. Для браузерних сценаріїв встановіть Playwright (`npm install --no-save --package-lock=false playwright`), запустіть dev-сервер і виконайте `node scripts/verify-practice6.mjs`. Потрібен Google Chrome. Скрипт використовує dev-режим для читання Pinia через Vue app.

Звіти, скріншоти та результати перевірок зберігаються поза проєктом. Скрипти перевірки за замовчуванням записують результати до `~/Downloads/TaskFlow-reports/practiceN/`. Каталоги `reports/` і `output/` виключені з Git.

## Практична робота № 7 (2-10.pdf)

- `database.js`: база `taskflow-db`, сховища `tasks`, `projects`, `metadata`, атомарний запис snapshot і окремий `deleteTaskRecord()`.
- `persistence.js`: відновлення Pinia перед mount, одноразові демонстраційні дані, послідовна черга записів, повтор після помилки. Пошук і фільтри не записуються.
- Статус і час останнього успішного збереження показано на сторінці завдань.
- Експорт JSON та імпорт із перевіркою типів, ID і projectId та підтвердженням заміни.
- Налаштування `/settings/` читають кількість збережених записів безпосередньо з IndexedDB.
- Одночасні вкладки використовують повні snapshots: останній запис може перезаписати зміни іншої вкладки. Автоматична синхронізація між вкладками не реалізована.

Перевірка: `npm run build`, потім `npm run preview`. Для офлайн-запуску спершу відкрийте production-версію онлайн та дочекайтеся активації service worker. База прив’язана до адреси, браузера й профілю; очищення даних сайту видаляє локальні записи. Звіти та результати перевірок зберігаються лише поза репозиторієм.
