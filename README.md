# TaskFlow

Навчальний PWA-менеджер завдань на Vue 3, Framework7 і Vite.

## Запуск

```sh
npm install
npm run dev
```

Production-збірка: `npm run build`; локальний перегляд: `npm run preview`.

## Можливості

- Головна зі статистикою (10 / 3 у роботі / 3 виконано / 4 заплановано) та прогресом 30%.
- Повторно використовувані TaskCard, StatusBadge, PriorityBadge та TaskCounter.
- Спільне реактивне сховище; зміна статусу і пріоритету через Props та Emits.
- Пошук у назві та описі, поєднані фільтри, сортування, деталі та підтверджене видалення.
- Адаптивний інтерфейс, фіксована навігація, сторінки About/Help.
- PWA manifest і service worker у production-збірці.

Стан зберігається у пам’яті й скидається після перезавантаження (відповідно до методички).

## Практична робота № 5 (2-8.pdf)

- TaskListControls: керований компонент з іменованими v-model для пошуку, статусу, пріоритету, сортування та швидкого фільтра.
- Видалення після підтвердження у доступному модальному діалозі; скасування кнопкою або Escape.
- Пошук одночасно у назві й описі, усі умови поєднуються; сортування не змінює вихідний масив.
- Усі 6 додаткових завдань: тільки невиконані, порядок статусів, частка виконаних у вибірці, очищення пошуку, окремий порожній список, зворотний порядок дат.
- Дата тепер необов’язкова, опис до 500 символів. Збережено категорії, форму й попередній перегляд.

Для повторення перевірок запустіть `npm run dev`, установіть Playwright (`npm install --no-save --package-lock=false playwright`) та Google Chrome, виконайте `node scripts/verify-practice5.mjs`.

Нижче збережено опис попередніх робіт; їхні тести й звіти стосуються відповідних станів проєкту. Робота № 4 доступна в коміті `9e1fb7a`.

## Практична робота № 4 (2-6.pdf)

- Створення й редагування через TaskForm, локальна копія та скасування.
- Валідація у формі та сховищі, попередній перегляд, повідомлення про збереження.
- Усі 7 додаткових завдань: категорії, перевірка дати, залишок символів, очищення, доступність, живий пошук, унікальність нових назв.
- Початкових записів 10. Стару дату можна залишити при редагуванні; нова дата має бути не в минулому.

Повторення перевірок: запустіть `npm run dev`, встановіть Playwright окремо (`npm install --no-save --package-lock=false playwright`), використайте встановлений Google Chrome, потім `node scripts/verify-practice4.mjs` і `node scripts/verify-practice4-store.mjs`.
